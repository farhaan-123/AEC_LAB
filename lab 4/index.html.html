Binomial Distribution

X ~ Binomial(n, p): the number of successes in n independent trials, each with success probability p.

Inputs

A positive integer (1, 2, 3, ...)
A number between 0 and 1
Selected: n = 20, p = 0.35

Binomial Statistics

Mean
–
np
Variance
–
np(1 − p)
Std. deviation
–
√Variance
Second moment E[X²]
–
Variance + Mean²
Skewness
–
(1 − 2p) / √(np(1 − p))

PMF Calculator: P(X = k)

An integer from 0 to n
P(X=k) = C(n,k) p^k (1-p)^(n-k)

CDF Calculator: P(X ≤ k)

An integer from 0 to n
P(X ≤ k)
–
Σ P(X = i), i = 0..k
P(X > k)
–
1 − P(X ≤ k)

P(X ≤ k) means the probability of getting k or fewer successes.
